Load this dependency before evaluating the forms that use its functions or variables. This preserves the existing startup dependency order.

** Create the chosen starter Org directory

Use the already resolved default or private override. This only prepares the selected directory; it does not discover or import another notes vault.

#+name: starter-setup-org-02-1
#+begin_src emacs-lisp
(unless (file-directory-p starter-org-directory)
  (make-directory starter-org-directory t))
#+end_src

** Point Org at the selected directory

The platform default or private override determines this path before the user Org module loads.

#+name: starter-setup-org-03-1
#+begin_src emacs-lisp
(setopt org-directory starter-org-directory
        org-default-notes-file (expand-file-name "inbox.org" starter-org-directory)
        org-agenda-files (list starter-org-directory))
#+end_src

** Apply policy after org

Waiting for the feature avoids racing its initialization. The following policy takes effect once its variables, maps or hooks exist; it does not force an unrelated feature to load now.

#+name: starter-setup-org-04-1
#+begin_src emacs-lisp
(with-eval-after-load 'org
  (setopt org-log-done 'time
          org-catch-invisible-edits 'show-and-error
          org-M-RET-may-split-line '((default . nil)))

  ;; Intentionally simple starter captures; replace them once your actual workflow is
  ;; understood rather than inheriting another person's ontology.
  (setopt org-capture-templates
          `(("t" "Inbox TODO" entry
             (file ,org-default-notes-file)
             "* TODO %?\n  %U\n")
            ("n" "Inbox note" entry
             (file ,org-default-notes-file)
             "* %?\n  %U\n"))))
#+end_src
