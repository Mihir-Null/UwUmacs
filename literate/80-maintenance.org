** Keep account and machine choices local

The generated example contains only comments. Copy it once to private.el and uncomment the settings you need. The real private.el is ignored by Git and excluded from every tangle output; rebuilding will never replace it.

** Open the reading guide

The path is relative to Lambda's resolved configuration root, so it works from any buffer or working directory.

** Build in a clean Emacs subprocess

Unsaved Org buffers are rejected before reading files from disk. A separate -Q process uses the bundled Org without loading personal startup; its output is displayed for review. Successful generation still requires a restart to apply configuration changes.

#+name: starter-setup-literate-02-1
#+begin_src emacs-lisp
(defun starter-literate--build (write)
  "Run the isolated literate builder; WRITE selects generation over checking."
  (let ((source-dir (expand-file-name "literate/" lem-emacs-dir))
        (output (get-buffer-create "*Emacs-Dots literate build*")))
    (dolist (buffer (buffer-list))
      (when-let* ((file (buffer-file-name buffer)))
        (when (and (file-in-directory-p file source-dir)
                   (buffer-modified-p buffer))
          (user-error "Save %s before building the literate configuration" file))))
    (with-current-buffer output
      (let ((inhibit-read-only t)) (erase-buffer)))
    (let ((status
           (call-process (expand-file-name invocation-name invocation-directory)
                         nil (list output t) nil
                         "-Q" "--batch" "-l"
                         (expand-file-name "tools/tangle.el" lem-emacs-dir)
                         "--" (if write "--write" "--check"))))
      (display-buffer output)
      (unless (equal status 0)
        (user-error "Literate build failed; see %s" (buffer-name output)))
      (message (if write
                   "Lisp regenerated. Restart Emacs to apply configuration changes."
                 "Literate sources and deployed Lisp agree.")))))
#+end_src

** Regenerate the deployed Lisp

This is the explicit write operation. The builder stages and validates all declared outputs before copying changed files into the configuration tree.

#+name: starter-setup-literate-03-1
#+begin_src emacs-lisp
(defun starter-literate-tangle ()
  "Regenerate deployed Lisp from saved literate sources."
  (interactive)
  (starter-literate--build t))
#+end_src

** Detect source/output drift

This read-only mode compares staged output with deployed Lisp. It catches edits to generated files and forgotten rebuilds without silently choosing one version.

#+name: starter-setup-literate-04-1
#+begin_src emacs-lisp
(defun starter-literate-check ()
  "Check that deployed Lisp matches saved literate sources without writing it."
  (interactive)
  (starter-literate--build nil))
#+end_src
