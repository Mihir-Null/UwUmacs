Ownership: *UwUmacs core*. This is the smallest piece of the configuration and
the most important one. It makes =SPC= an ordinary Emacs prefix keymap while
Meow is in Normal or Motion state, and it gives every major mode its own menu
under =SPC m=. Nothing here knows about Lambda, packages or this machine.

* Why a real keymap instead of Meow's keypad

Meow ships a "keypad": press =SPC=, and Meow starts a small loop that reads
keys one at a time and *translates* them into another key sequence
(=SPC x f= becomes =C-x f=). That is clever, but it means =SPC f f= is not a
binding anywhere. Emacs's own tools cannot see it: =C-h k= cannot describe it,
=C-h b= does not list it, which-key shows the translated keys, and M-x
annotations show the =C-x= form you never type. Earlier versions of this
configuration patched those tools one by one.

An Emacs keymap is just a tree of keys. If =SPC= is bound to a keymap in the
Normal-state map, then =SPC f f= is a real binding: every help command,
which-key and Marginalia see exactly the keys you press. Meow's documented
helper for adding keys to a state accepts a keymap as the value, so the whole
leader is two lines. The keypad is still available as the command
=meow-keypad=; it is simply not bound unless you ask for it below.

#+begin_src emacs-lisp
;;; uwumacs-leader.el --- A literal leader and localleaders for Meow -*- lexical-binding: t; -*-
;; Generated from literate/41-leader.org; edit the Org source, then tangle.

;;; Commentary:
;; SPC becomes an ordinary prefix keymap in Meow's Normal and Motion states,
;; and every major mode gets its own map under SPC m.  Everything is a native
;; keymap, so C-h k, C-h b, which-key and Marginalia see the real keys.

;;; Code:

(require 'meow)

(defgroup uwumacs nil
  "UwUmacs: a literal, discoverable leader for Meow."
  :group 'convenience
  :prefix "uwumacs-")

(defcustom uwumacs-leader-key "SPC"
  "Key that opens `uwumacs-leader-map' in Meow's Normal and Motion states."
  :type 'key)

(defcustom uwumacs-localleader-key "m"
  "Key below the leader that opens the current major mode's localleader map."
  :type 'key)

(defcustom uwumacs-keypad-key nil
  "Optional key below the leader that starts Meow's keypad translation loop.
Nil leaves `meow-keypad' unbound; it stays available as a command."
  :type '(choice (const :tag "Unbound" nil) key))

#+end_src

* The leader map

=uwumacs-leader-map= is a plain keymap. Add a command with =keymap-set=. To
add a labelled group, bind a key to a cons of a label and a keymap; which-key
prints the label instead of the anonymous "+prefix". Both forms are standard
Emacs, not a UwUmacs invention, so anything that understands keymaps
understands the leader.

#+begin_src emacs-lisp :tangle no
(keymap-set uwumacs-leader-map "f f" #'find-file)
(keymap-set uwumacs-leader-map "f" (cons "files" my-file-map))
#+end_src

#+begin_src emacs-lisp
(defvar uwumacs-leader-map (make-sparse-keymap)
  "The leader map, opened by `uwumacs-leader-key' in Normal and Motion states.
Add a command with `keymap-set'.  Add a labelled group with
  (keymap-set uwumacs-leader-map \"f\" (cons \"files\" my-file-map)).")

#+end_src

* Localleaders: one menu per major mode

Evil has per-mode Normal-state keymaps; Meow does not. The native way to get
a buffer-specific prefix is =emulation-mode-map-alists=: a list whose entries
are alists of (MINOR-MODE-VARIABLE . KEYMAP), consulted before minor-mode and
major-mode maps. An entry may be a *symbol* whose value is read in the current
buffer, so a buffer-local variable there gives each buffer its own map. The
entry below keys its map on Meow's own state variables, so the localleader
appears in Normal and Motion and vanishes in Insert.

Maps are registered per major mode in =uwumacs-localleader-alist= and composed
along the mode's parents, most specific first. A map for =prog-mode= is
inherited by every programming mode; a map for =emacs-lisp-mode= overrides the
keys it redefines and inherits the rest.

#+begin_src emacs-lisp
(defvar uwumacs-localleader-alist nil
  "Alist of (MAJOR-MODE . KEYMAP) localleader maps.
Maps compose along the mode's parents, most specific first, so a map for
`prog-mode' is inherited by every programming mode.")

(defvar-local uwumacs--localleader-alist nil
  "This buffer's emulation-map entry: its composed localleader under the leader.")

(defun uwumacs-localleader-map (&optional mode)
  "Return the composed localleader keymap for MODE, or nil if none applies.
MODE defaults to the current major mode."
  (let ((maps (delq nil (mapcar (lambda (parent)
                                  (alist-get parent uwumacs-localleader-alist))
                                (derived-mode-all-parents (or mode major-mode))))))
    (when maps (make-composed-keymap maps))))

(defun uwumacs--install-localleader ()
  "Point this buffer's emulation entry at its localleader, if it has one."
  (setq uwumacs--localleader-alist
        (when-let* ((local (uwumacs-localleader-map))
                    (wrapper (define-keymap
                               uwumacs-leader-key
                               (define-keymap uwumacs-localleader-key
                                 (cons "mode" local)))))
          `((meow-normal-mode . ,wrapper) (meow-motion-mode . ,wrapper)))))

(defun uwumacs-refresh-localleaders ()
  "Recompute the localleader of every live buffer."
  (dolist (buffer (buffer-list))
    (with-current-buffer buffer (uwumacs--install-localleader))))

(defun uwumacs-define-localleader (mode &rest definitions)
  "Give MODE a localleader built from DEFINITIONS and refresh live buffers.
DEFINITIONS are `define-keymap' arguments: KEY DEFINITION pairs, where a
definition may be (cons \"label\" COMMAND) to label it for which-key.
Calling this again for MODE replaces its map."
  (declare (indent 1))
  (setf (alist-get mode uwumacs-localleader-alist) (apply #'define-keymap definitions))
  (uwumacs-refresh-localleaders)
  mode)

#+end_src

Defining a localleader is one form per mode. The rest of this configuration
adds these next to the package they belong to, so the Magit chapter defines
Magit's menu and the Org chapter defines Org's.

#+begin_src emacs-lisp :tangle no
(uwumacs-define-localleader 'emacs-lisp-mode
  "e" (cons "eval buffer" #'eval-buffer)
  "d" (cons "edebug defun" #'edebug-defun))
#+end_src

* Turning it on, and seeing what you have

=uwumacs-leader-enable= binds the leader in both states, registers the
localleader entry once, and refreshes every buffer. It is safe to call again.
=uwumacs-describe-leader= opens the standard help view for the leader plus this
buffer's localleader; =C-h k SPC f f= and which-key work without any help from
this file.

#+begin_src emacs-lisp
(defun uwumacs-describe-leader ()
  "Describe the leader bindings, including this buffer's localleader."
  (interactive)
  (let ((map (make-sparse-keymap)))
    (set-keymap-parent map uwumacs-leader-map)
    (when-let* ((local (uwumacs-localleader-map)))
      (keymap-set map uwumacs-localleader-key (cons "mode" local)))
    (describe-keymap map)))

(defun uwumacs-leader-enable ()
  "Bind the leader in Meow's Normal and Motion states and start localleaders.
Safe to call more than once."
  (meow-normal-define-key (cons uwumacs-leader-key uwumacs-leader-map))
  (meow-motion-define-key (cons uwumacs-leader-key uwumacs-leader-map))
  (when uwumacs-keypad-key
    (keymap-set uwumacs-leader-map uwumacs-keypad-key #'meow-keypad))
  (add-to-list 'emulation-mode-map-alists 'uwumacs--localleader-alist)
  (add-hook 'after-change-major-mode-hook #'uwumacs--install-localleader)
  (uwumacs-refresh-localleaders))

(provide 'uwumacs-leader)
;;; uwumacs-leader.el ends here
#+end_src

* Checking it

[[file:../tests/uwumacs-leader-tests.el][uwumacs-leader-tests.el]] loads only Meow and this module and checks the
five promises above: =SPC= is a prefix in Normal and Motion, a space in Insert
still inserts a space, localleaders override and inherit along the mode
lineage, other buffers see nothing, and the keypad is unbound unless
=uwumacs-keypad-key= is set. Run it from the repository root:

#+begin_src sh :tangle no
EMACS_DOTS_TEST_PACKAGES=/path/to/var/elpa emacs -Q --batch -l tests/uwumacs-leader-tests.el -f ert-run-tests-batch-and-exit
#+end_src
