* Start here

This sheet describes the Meow + Lambda bindings in Emacs-Dots.
=C-= means Ctrl, =M-= means Alt, =SPC= means Space, and =RET= means Enter.
Keys separated by spaces are pressed in sequence; uppercase letters use Shift.

In Meow normal or motion state, press =SPC= and pause for the which-key menu.
In insert state, use =C-c C-SPC= for native access to the leader map, or Escape
first for Meow keypad. These routes differ where a submenu has Control bindings;
see the project exceptions below.
Use =M-x= to run any command below by name. =C-g= cancels a prompt.

The SPC menu title shows the physical keys already entered; its rows show the
next key to press. For example, after =SPC f=, press =f= for =find-file=.
M-x command annotations also prefer complete physical leader sequences, such as
=SPC s s= for =consult-line=, when opened from Normal or Motion state. In Insert
state, or when a command has no reachable SPC binding, they retain native Emacs
shortcuts. These annotations describe shortcuts from the editing buffer; type
the command name or select a candidate while the M-x prompt itself is open.

|-----------+------------------------------+----------------------------------|
| SPC SPC   | Run a command                | execute-extended-command         |
| SPC h     | Return to the dashboard      | dashboard-open                   |
| SPC H     | Open this sheet              | starter-dashboard-open-cheatsheet |

Try =M-x meow-tutor= for guided editing practice. For the complete live maps,
run =M-x describe-keymap= and choose =lem+leader-map= or =meow-normal-state-keymap=.
Those live maps include your later customizations; this sheet is a curated guide.
A raw map entry is not proof that a command exists or that keypad input reaches
it. =SPC ?= currently names =consult-apropos=, which is unavailable in the
inspected installation. Use =M-x apropos-command= or search directly in =M-x=.
The hints-only change describes the current bindings; it does not repair that
underlying dead binding.

* Meow: select, then act

Normal state moves/selects text; insert state types text. Start with =w= to
select a word, then =c= to replace it. Press Escape to return to normal state.

** Project keypad exceptions

At the second and later keypad keys, Meow tries Control first and then the
literal key. The native project map contains both forms, so typing the same
letters through keypad can reach a different binding:

| Input             | Current keypad result                                  |
|-------------------+--------------------------------------------------------|
| =SPC p b=         | =project-list-buffers= (the map's =C-b= entry)           |
| =SPC p x=         | Opens the map's =C-x= prefix; it does not run a command  |
| =SPC p x s=       | =project-save-some-buffers=                             |

Use =M-x consult-project-buffer= to switch project buffers and
=M-x project-execute-extended-command= to run a command in the project.
Native leader input also bypasses keypad translation: =C-c C-SPC p b= and
=C-c C-SPC p x= reach those respective commands. Press the initial Control
chords as shown, then release Control for the remaining letters. Reaching the
native Control entries explicitly instead requires =C-c C-SPC p C-b= or
=C-c C-SPC p C-x s=.

The audit found 25 top-level project entries: 23 plain/Shift and two Control
entries. The two Control entries also shadow =b= and =x= under keypad, producing
four affected map paths, not just two. The keypad results above were checked
with Meow's own lookup functions; that is dispatch simulation, not a claim
that each key sequence was physically exercised in a graphical session.

** Frames and internal windows

=SPC w= shows window commands; =SPC W= shows workspace commands.
Frames are OS windows managed by your desktop. A window is an internal pane,
a buffer holds text, and a tab remembers a window layout. With frames-only-mode,
=C-c C-SPC w h= / =C-c C-SPC w v= create frames and =C-x 4= uses
other-frame commands. The frame tests exercise the native Control leader route;
they do not establish that =SPC w h= / =SPC w v= apply the same command
remapping through Meow keypad. Use the native forms above for verified frame
actions.
Completion panels remain inside the editor. =M-x frames-only-mode= toggles the
policy and restores the original split keys when disabled.
For Git without optional packages, start with =M-x vc-dir=.

* Completion setup and known integration gaps

The current stack uses Vertico for minibuffer candidates, Consult for commands
such as line search, Orderless for matching, Marginalia for annotations, Embark
for candidate actions, and Corfu for completion at point. Which-key explains
prefix maps. The hints-only branch keeps this stack and Meow keypad behavior.

The P00 review found no =embark-consult= package or explicit declaration in the
inspected setup; do not assume Consult-specific Embark integration is active.
The graphical audit also found both =kind-icon-margin-formatter= and
=nerd-icons-corfu-formatter= configured, with kind-icon first. Those are recorded
integration issues, not repairs or package changes made by this guide.

* Symbols not showing?

- =M-x describe-char= describes the character at point, including its font.
- =M-x describe-variable RET nerd-icons-font-family= shows the icon font name.
- The default is =Symbols Nerd Font Mono=. The GUI must see that exact family;
  installing a font and configuring an icon consumer are separate steps.
- After installing a font in Windows, restart Emacs. In a terminal, configure
  the terminal emulator's font instead.
